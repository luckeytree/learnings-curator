# guides/

The curator creates guides here as your learnings arrive. A new install has none.

A guide holds rules that matter in one recognizable situation (writing for customers, reviewing
a pull request, a kind of project you do often) and don't need to be in every session. Your
global file says when to open each one, so a guide costs nothing until the work calls for it.

A guide gets made when at least three rules share a situation. Fewer than that, and they wait
in the closest guide or stay out. See [`../examples/guide-example.md`](../examples/guide-example.md)
for the shape.
